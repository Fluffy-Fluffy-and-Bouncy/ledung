# Contributing to Ledung

Thank you for wanting to help. Ledung is dual-licensed: under the GNU AGPL version 3 ([LICENSE](LICENSE)) and under a commercial license ([COMMERCIAL.md](COMMERCIAL.md)). The commercial license is only possible while the copyright holders, Martin Strålenhielm and Simon Rasmussen, may license every part of Ledung that way.

## Contributor license agreement

**An outside contribution needs a signed contributor license agreement (CLA) before it can be merged.** The CLA lets the copyright holders license your contribution under both the AGPL and the commercial license; you keep the copyright of your own work. The CLA text is not published yet: until it is, open an issue first and say what you would like to change, and we will tell you how to sign before you send a pull request. A pull request without a signed CLA is not merged.

## How the project works

Read [CLAUDE.md](CLAUDE.md) for how the repository is worked on: decisions go in [docs/decisions.md](docs/decisions.md), every change to what Ledung does adds a line to [CHANGELOG.md](CHANGELOG.md), and `npm run check` must pass before a push.
