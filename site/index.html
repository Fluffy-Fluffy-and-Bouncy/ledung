Your Claude Code sessions, sailing as one fleet.

Ledung runs several Claude Code sessions on your own computer and shows them on one page: who started what, which questions are waiting for you, every permission prompt, tokens and machine load.

Install LedungContact us




  

    

    

      
A manager runs the sessions. You run the manager.

      
Give each project a manager: a Claude session that starts the work, hands out tasks and answers the ordinary prompts of the sessions under it. Ledung records who started whom, so the whole tree is in the sidebar, each with a ship that sails while it works and stops when it waits.

      
You can open any session and talk to it directly, whenever you want.

    

  






  

    

    

      
Questions land in one list, not buried in chats.

      
When a session needs you it asks through Ledung. Every question is stored in Waiting for you, grouped by what it blocks, with the issue, the evidence and a recommended answer. Your answer goes straight back to the session that asked.

    

  






  

    

    

      
Sensitive calls always reach you.

      
Managers may allow routine commands for their sessions, and every decision is labelled with who made it. Anything your project marks sensitive, like production, deploys or customer data, is never decided by a manager. It waits for you, even while you are away.

    

  






  

    

    

      
From your phone

      
Away from the desk, still at the helm.

      
    
        
  • Anywhere, end to end encrypted. Ledung dials out to a relay, one you run yourself or one you join with a code from whoever runs it, so your computer needs no open port. Pair your phone once with a QR code.
    • 
        
  • A passkey for changes. The phone can look at once; Face ID or a fingerprint unlocks it to answer and decide. Sensitive prompts are signed one by one.
    • 
        
  • A nudge when you're needed. A push notification for each new question or permission prompt, even with Ledung closed. It names the computer, never what was asked.
    • 
        
  • Or the Claude app. Each manager turns on Claude Code's Remote Control, so you can talk to it from there too.
    • 
      

    

  






  

    
All your computers, one page
Link your computers' Ledungs once. Each shows as a tab with what waits there, and their managers message each other across them.

    
Managers that talk to your team's
Managers post to managers in other people's Ledungs through a GitHub repository you pick. You see each file before it leaves.

    
Sign off on one page
A finished change comes as a review: what was solved, what was done, the evidence. Screenshots get Pass, Fail or Unsure.

  






  

    

      
Away mode
Leave for the evening. The manager keeps work moving within what you allowed and holds the rest for you.

      
Usage you can see
Tokens per session, rolled up per manager, with your plan's limits and the machine's CPU and memory.

      
Updates without stopping
Run npm install -g ledung again and press Restart Ledung. Sessions keep running through the restart.

      
Windows, macOS, Linux
Projects in plain folders or in dev containers. Everything stays on your machine.

    

  






  

    

      Ledung 1.0.0 on npm
      
Two commands to set sail.

      
npm install -g ledung
ledung

      
You need Node.js 24 or later, Git, and Claude Code installed and signed in. Ledung opens in your browser; install it as an app window from Edge or Chrome.

      
The code is on GitHub, the package on npm.
